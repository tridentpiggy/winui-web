按钮与菜单

按钮家族、下拉、分裂按钮、ComboBox 和 MenuFlyout。

按钮

HTML

<div winui-prev="AccentButton" winui-content="强调按钮"></div>
<button winui-prev="ToggleButton" winui-content="切换按钮"></button>

下拉与选择

HTML
<div winui-prev="DropDownButton" winui-content="操作" winui-items='["新建","打开"]'></div>
<div winui-prev="ComboBox" winui-placeholder="选择水果" winui-items='["苹果","香蕉"]'></div>

使用说明

引入

<link rel="stylesheet" href="winui.css">
<script src="winui.js" defer></script>
<div winui-prev="TextBox" winui-placeholder="输入内容"></div>

通用属性

winui-prev       组件类型
winui-content    标题或标签文本
winui-placeholder 输入提示
winui-items      下拉/列表 JSON 数组
winui-value      初始数值或进度
winui-checked    初始勾选状态
winui-disabled   true 时禁用
winui-min/max    范围控件边界
winui-group      单选按钮组名
