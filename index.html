调用说明

引入 CSS 和 JS，把组件类型写入普通元素的 winui-prev 属性即可。

快速开始

<link rel="stylesheet" href="winui.css">
<script src="winui.js" defer></script>
<div winui-prev="Button" winui-content="Hello WinUI"></div>

公共属性

winui-prev          组件类型（所有组件统一入口）
winui-content       显示文本
winui-items         下拉项 JSON 数组
winui-disabled      true 时禁用
winui-checked       ToggleButton 初始选中
winui-target        SidebarToggle 目标侧边栏选择器
winui-collapsed     Sidebar 初始折叠
winui-value         ProgressBar 数值 0–100
winui-indeterminate="true"  不确定进度动画
