按钮

按钮家族示例。点击左侧目录切换组件页；每页包含控件预览和直接可用的 HTML 调用代码。

普通、强调、切换与超链接

HTML 调用
<div winui-prev="Button" winui-content="标准按钮"></div>
<div winui-prev="AccentButton" winui-content="强调按钮"></div>
<button winui-prev="ToggleButton" winui-content="切换按钮"></button>
<div winui-prev="HyperlinkButton" winui-content="超链接按钮"></div>
<div winui-prev="Button" winui-content="禁用按钮" winui-disabled="true"></div>

下拉与选择

下拉菜单、分裂按钮和可编辑 ComboBox，支持点击、键盘导航和弹出动画。

预览

HTML 调用
<div winui-prev="DropDownButton" winui-content="文件操作"
  winui-items='["新建","打开","保存","另存为"]'></div>
<div winui-prev="SplitButton" winui-content="运行"
  winui-items='["运行","以管理员身份运行","调试"]'></div>
<div winui-prev="ComboBox" winui-placeholder="选择水果"
  winui-items='["苹果","杏子","香蕉","蓝莓","橙子","梨"]'></div>

  <div winui-prev="Sidebar" id="nav" winui-label="主导航">

HTML 调用

<div winui-prev="ProgressBar" winui-indeterminate="true"></div>
<div winui-prev="ProgressBar" winui-value="64"></div>

调用说明

引入两个文件，把组件名写入任意普通元素的 winui-prev 属性即可。

最小页面

<!doctype html>
<html lang="zh-CN">
<head>
  <link rel="stylesheet" href="winui.css">
  <script src="winui.js" defer></script>
</head>
<body>
  <div winui-prev="Button" winui-content="Hello WinUI"></div>
</body>
</html>

统一属性

winui-prev       组件类型（所有组件共同入口）
winui-content    按钮标题或显示文本
winui-items      下拉/选择项的 JSON 数组
winui-disabled   true 时禁用控件
winui-checked    ToggleButton 初始选中状态
winui-target     SidebarToggle 控制的侧边栏 CSS 选择器
winui-collapsed  Sidebar 初始折叠状态
winui-value      ProgressBar 数值，范围 0–100
winui-indeterminate="true"  不确定进度动画
